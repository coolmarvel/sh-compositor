# 프로젝트 브리프: sh-compositor (가칭 — 이름은 추후 확정)

## 한 줄 정의

포토샵이 비싸서 무료로 풀린 macOS 전용 오픈소스 에디터 **Compositor(MIT)** 를, Windows 에서 쓸 수 있는
**오프라인 설치형 포토샵형 이미지 편집기**로 옮기고, 겉모습은 사용자 자매 앱들(sh-messenger·remote-assist·
sh-web-editor·파일 변환기)과 같은 **클래식 업무 UI** 로 감싼다.

## 문제와 사용자

- **문제**: Photoshop 은 비싸고 GIMP 는 손에 익지 않는다. Compositor 는 좋은 무료 대안이지만 Swift/macOS 전용이라
  사용자(Windows) 환경에서 실행할 수 없다.
- **사용자**: 제작자 본인(이성현)과 주변 — 합성·보정·리터칭을 포토샵 문법으로 하려는 사람.

| 유형 | 이 앱에서 하는 일 |
|---|---|
| 편집자 | 사진을 열어 레이어로 합성하고, 선택·마스크·브러시·보정·필터로 다듬어 PNG/JPEG 로 내보낸다 |

## 핵심 시나리오 (v1.0 — 사용자 지시: "전부")

1. 새 캔버스/이미지 열기(여러 장 = 탭), 레이어 추가·삭제·순서·숨김·불투명도·합성 모드·폴더·병합.
2. 이동·크기·회전·반전·자유 변형(네 모서리), 수치 입력, 스냅.
3. 선택: 사각·타원·올가미·다각형 올가미·마법봉, 더하기/빼기, 반전·확장·축소·페더, 선택 영역 픽셀 이동·복사.
4. 칠하기: 브러시·지우개(크기·경도·불투명도), 그라데이션, 도형(사각·둥근 사각·타원·선), 문자, 스포이트·색 선택.
5. 리터칭: 스팟 복구, 복제 도장, 흐림/문지르기/리퀴파이.
6. 레이어 마스크(칠하기·반전·흐림·페더)·클리핑 마스크·조정 레이어(레벨·커브·색조/채도·노출·그라데이션 맵·그레인).
7. 필터: 가우시안·모션 블러, 노이즈, 렌즈 보정, 배경 제거, 내용 인식 채우기. 레이어 효과(외곽선·그림자 등).
8. 자르기(스냅·Alt 대칭), 캔버스 크기·이미지 크기, 캔버스 반전, 실행취소/다시실행, 포토샵식 단축키.
9. 프로젝트 저장/열기(레이어 유지), PNG/JPEG(미리보기) 내보내기, 클립보드 복사/붙여넣기.

## 제약

- **플랫폼/형태**: Windows 데스크톱 설치형(NSIS), 완전 오프라인. macOS 빌드는 추후.
- **UI**: 자매 앱과 같은 클래식(반경 0·1px·12px 돋움·베벨 버튼·자체 타이틀바·메뉴 바·상태 줄·스킨). Compositor 의
  **화면 구조**(도구 헤더·도구 레일·캔버스·레이어 패널·상태 줄·탭)를 그대로 쓰되 껍데기만 클래식으로 입힌다.
- **라이선스**: Compositor 는 MIT — 저작권 표시 유지(정보 창·LICENSE-THIRD-PARTY).
- **비용**: 유료 API 없음.
