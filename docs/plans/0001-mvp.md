# 0001 MVP — Compositor 전 기능

사용자: 첫 마일스톤에 "전부". 아래 순서로 쌓되, 마일스톤마다 설치해 만져 볼 수 있게 한다.
출처 파일은 `~/Compositor/Compositor/` 기준.

## M1 문서·레이어·뷰 (`Document/EditorSession`, `LayersPanel`, `CanvasViewport`, `LayerRenderer`)
- [x] 클래식 셸(타이틀바·메뉴 7개·도구 헤더·도구 레일·레이어 패널·상태 줄·탭)
- [x] 새 캔버스·이미지 열기·드롭·붙여넣기, 탭(여러 문서)
- [x] WebGL2 합성(합성 모드 16종·불투명도·숨김), 체커보드, 팬/줌/맞춤/100%, 픽셀 그리드
- [x] 레이어: 추가·삭제·복제·이름·순서(드래그)·폴더·병합(아래로/선택/폴더)
- [x] 실행취소/다시실행(스냅샷 공유)
- [x] PNG/JPEG(미리보기) 내보내기, 프로젝트 저장/열기(.shcomp)
- [ ] Compositor `.comp` 폴더 직접 열기 (형식은 호환 — 폴더 선택 UI 미구현)

## M2 변형·자르기·캔버스 (`LayerTransform`, `TransformOverlay`, `Distort`, `Crop`, `CanvasSizeSheet`)
- [x] 이동·크기·회전·반전(레이어·캔버스), 자유 변형, 수치 입력, 스냅·가이드
- [x] 자르기(스냅·Alt 대칭·비율), 캔버스 크기·이미지 크기

## M3 선택 (`Selection`, `SelectionEdits`, `MagicWand`, `SelectionClipboard`)
- [x] 사각·타원·올가미·다각형 올가미·마법봉, 더하기/빼기, 모두·해제·반전·확장·축소·페더
- [x] 선택 이동·픽셀 이동/복제, 잘라내기·복사·병합 복사·붙여넣기, 채우기·지우기, 선택 영역으로 레이어

## M4 칠하기 (`BrushStroke`, `Gradient`, `ShapeTool`, `TypeTool`, `ColorPalette`)
- [x] 브러시·지우개(크기·경도·불투명도·Shift 직선), 스포이트·색 선택기·전경/배경색
- [x] 그라데이션(선형·원형), 도형(사각·둥근 사각·타원·선), 문자(상자·글꼴·크기·색·정렬)

## M5 마스크·효과·조정 레이어 (`LayerMask`, `LiveLayerMask`, `LayerEffects`, `LayerAdjustment`)
- [x] 레이어 마스크(칠하기·채우기·반전·켜기/끄기·적용·삭제), 클리핑 마스크
- [ ] 마스크 흐림·페더 명령, 폴더 마스크, 마스크 링크 해제 UI
- [x] 조정 레이어(레벨·커브·색조/채도·노출·그라데이션 맵·그레인), 레이어 효과

## M6 보정·필터·리터칭 (`Filters`, `Levels`, `Curves`, `HueSaturation`, `CloneStamp`, `HealPixels`, `SmudgeLiquify`, `ContentFill`)
- [x] 보정 대화상자(선택 영역 한정 적용), 필터 전부, 배경 제거, 내용 인식 채우기
- [x] 스팟 복구, 복제 도장(정렬·모든 레이어), 흐림/문지르기/리퀴파이
