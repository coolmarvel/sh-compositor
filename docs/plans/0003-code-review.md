# 코드 검수 범위

요청: 웹 전환 가능성 확인, A~Z 실행 흐름의 성능·중복·미사용·복잡도 점검과 리팩토링.
기존 미커밋 v1.0.0~1.0.3 작업을 보존한다. 웹 제품 배포 자체는 이번 범위에 포함하지 않는다.

- [x] 순수 코어: 합성·변형·선택·필터·PNG/PSD/프로젝트의 버퍼 복사와 할당 점검
- [x] 도구→미리보기→GPU→이력 흐름 점검, CPU 합성의 불필요한 문서 크기 버퍼 제거
- [x] 저장·자동 저장의 비동기 경합, Worker 오류·요청·자원 수명 정리
- [x] Electron IPC 구독 해제, 모델 파일 서빙 중복과 경로 경계 점검
- [x] UI·패널·미사용 코드 정리, TypeScript 미사용 검사 적용
- [x] 차등/경합 단위 검증(전체 75건), 전체 Electron E2E(115건), 성능 전후 측정, Windows v1.0.4 설치본
- [x] 검수 결과 및 남은 웹 전환 경계를 문서화 (`guides/code-review.md`, `adr/0004-background-lifecycle.md`)

코드와 테스트가 근거인 변경만 적용한다. 파일 길이를 줄이기 위한 기계적 분할이나 새 언어의 무조건적인 확대는 하지 않는다.
