# Plans — 기획·설계 문서

이 폴더는 **아직 구현되지 않은** 기획·설계·로드맵을 담는다. `docs/guides/` 가 "현재 구현된 동작"을
기록하는 것과 반대로, `plans/` 는 **앞으로 만들 것**을 기록한다.

> 문서 작성 규칙은 `docs/writing-guide.md` 를 따른다. 단 "현재 코드 기준으로만 작성" 원칙은
> `guides/` 에 적용되는 것이고, 이 폴더는 forward-looking 설계를 담는 예외 공간이다.

## ADR·guides 와의 관계

| 위치 | 답하는 질문 |
|---|---|
| `docs/adr/` | **왜** 이렇게 결정했나 (대안·트레이드오프) |
| `docs/plans/` | **무엇을·어떤 순서로** 만들 것인가 |
| `docs/guides/` | **현재** 어떻게 동작하나 (코드가 진실) |

설계 결정이 확정되면 ADR 에 박제하고, 그 결정을 따라 만들 작업의 묶음·순서는 plans 에 둔다.
기능이 실제 구현되면 내용은 `guides/` 로 옮기고 plans 에는 체크 표시만 남긴다.
