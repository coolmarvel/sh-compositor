# 체인지로그 (릴리스 단위)

사람용 요약 — 릴리스(버전 승격·배포) 단위로만 기록한다. 세부 이력은 `session-log.md`.

## v1.1.0 — 2026-09-22

- 배경 제거·피사체 선택처럼 오래 걸리는 작업 중에 다른 탭으로 바꾸면 결과가 그 탭에 들어가던 문제 수정 (시작한 탭에만, 그사이 문서가 바뀌었으면 적용하지 않고 알림)
- 실행 취소 메모리 한도 (편집 ▸ 환경 설정 "실행 취소 메모리", 기본 1024MB) — 넘으면 오래된 단계부터 지움. 작업 내역 패널에 사용량 표시
- 탭을 닫으면 그 탭을 위해 돌던 배경 제거·인코딩을 그만 기다림, 개체 선택 모델이 멈추면 제한 시간 뒤 정리
- **웹 로컬 편집기** (`npm run build:web`) — 설치 없이 브라우저에서 같은 편집기. 저장은 파일 저장/다운로드, 자동 저장은 브라우저 저장소
- **headless 서버와 MCP** (`npm run build:server`) — 브라우저 없이 PNG 가져오기·크기·자르기·레이어·필터·내보내기. AI 클라이언트가 MCP 도구로 호출 (토큰 인증)

## v1.0.4 — 2026-09-22

- CPU 합성·올가미 계산의 불필요한 반복과 메모리 할당 감소
- 저장 중 탭을 바꾸거나 계속 편집했을 때 저장 상태가 잘못 표시되는 문제 수정
- 자동 저장 중복 실행과 종료 중 복구 파일 재생성 방지
- Worker·창 이벤트·GPU 자원 정리, 파일 교체 저장과 이미지 입력 검증 보완

## v1.0.3 — 2026-09-22

- 흐림·문지르기·리퀴파이에서 이미지 전체를 반복 복사하던 병목 제거
- 세 도구의 픽셀 계산을 내장 Rust WebAssembly로 가속, 인터넷 없이 동작

## v1.0.2 — 2026-09-21

- **사용 설명서** (도움말 ▸ 사용 설명서, F1) — 시작하기·도구·선택·칠하기·색 보정·레이어·화면과 파일 탭으로 나눠 어떤 키가 무엇을 하는지 정리
- 설치 파일 430MB → 247MB, 설치 폴더 약 1.2GB → 597MB (배경 제거 모델이 두 번 들어가던 것 등 중복 제거)

## v1.0.1 — 2026-09-21

- **개체 선택 (AI, W)** — 피사체를 사각형이나 올가미로 넉넉히 감싸거나 문지르면 테두리에 딱 맞게 선택 (인터넷 없이)
  - Shift+클릭은 여기도 포함, Alt+클릭은 여기는 빼기. 옵션 줄의 테두리·부드럽게 슬라이더로 넓히고 줄이기
- **가장자리 다듬기** (Ctrl+Alt+R) — 머리카락·털 같은 가는 테두리 살리기, 바깥 어둡게 보며 조정
- 조정 추가: 흑백(Ctrl+Shift+Alt+B)·색상 균형(Ctrl+B)·활기·포스터화·한계값, 이미지 ▸ 조정 하위 메뉴로 정리
- 필터 추가: 선명하게(언샤프 마스크·하이 패스), 모자이크, 노이즈 감소
- 이동 도구 옵션 줄에 정렬·분포 버튼, 레이어 효과에 외부 광선, 레이어 효과 복사·붙여넣기
- 히스토그램 패널

## v1.0.0 — 2026-09-21

- **Photoshop PSD 열기·저장** — 레이어·폴더·마스크·효과·조정 레이어·혼합 모드·잠금 그대로 (옮기지 못하는 것은 알려 줌)
- **훨씬 빨라짐** — 큰 사진에서 레이어 끌기·붓질이 끊기지 않게 (바뀐 영역만 다시 그림, 저장은 뒤에서)
- 배경 제거 중에도 화면이 멈추지 않음, 진행 막대 두 단계(모델 불러오기 % → 분석)
- 눈금자·안내선(끌어 만들기·붙기), AI 피사체 선택, 레이어 잠금, 선 그리기, 선택 매끄럽게
- 브러시 필압(굵기·진하기)과 사전 설정, 견본·내비게이터 패널, 색 선택 HSB
- 도형을 나중에 다시 고치기(크기를 바꿔도 또렷), 세로쓰기, 스냅샷, 환경 설정
- 레이어를 각각 PNG로·선택 영역을 PNG로 내보내기
- Ctrl+끌기로 어느 도구에서나 이동, 문자 확정(Ctrl+Enter) 뒤 바로 이동·변형
- 고친 것: 확정 안 한 그라데이션이 남아 새 결과가 안 보이던 문제, 캔버스를 누르면 화면이 밀려 올라가던 문제,
  폴더 마스크가 자르기·캔버스 크기·회전에서 깨지던 문제, 탭 표시 잘림, 설명 문구·줄바꿈 정리

## v0.1.1 — 2026-09-21

- 처음 연 문서가 창을 최대화해도 화면 가운데에 오도록, 창 크기를 바꿔도 보던 곳 유지
- 레이어 썸네일이 칸 밖으로 넘치던 문제 수정
- 배경 제거: **최신 모델(온라인)** / 내장 모델(오프라인) / 자동 선택 — 오프라인이면 안내
- Compositor `.comp` 폴더 열기, 최근 파일, WebP 내보내기, 자동 저장·비정상 종료 복구
- 폴더 마스크, 마스크 반전·페더, 상태 줄 커서 좌표·색
- 화면이 가만히 있어도 다시 그리던 낭비 제거 (선택 영역이 있을 때 가벼워짐)
