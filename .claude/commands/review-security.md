# /review-security — 보안 리뷰

현재 변경분(또는 인자로 지정한 범위)을 보안 관점에서 리뷰한다.

## 점검 항목

1. **시크릿**: 하드코딩된 토큰/키/비밀번호, `.env` 값의 코드·문서·로그 유출
2. **입력 검증**: 외부 입력(폼·쿼리·파일 업로드·API 바디)이 검증 없이 사용되는 곳
3. **인젝션**: SQL/커맨드/경로 조작 — 문자열 조립으로 쿼리·명령·경로를 만드는 곳
4. **XSS/출력 이스케이프**: 사용자 입력이 HTML 로 렌더되는 경로
5. **인증·인가**: 보호돼야 할 라우트/기능에 권한 검사 누락, IDOR(남의 리소스 id 접근)
6. **PII/로그**: 개인정보·민감정보가 로그·에러 메시지·분석 도구로 흘러가는 곳
7. **의존성**: 알려진 취약 버전, 불필요하게 넓은 권한의 패키지

## 출력 형식

발견 항목을 **Critical / Warning / Info** 로 분류하고, 각 항목에 `파일:라인` 을 인용한다.
수정 제안을 함께 제시하되, 적용은 사용자 승인 후에 한다. 발견이 없으면 "없음"을 항목별로 명시한다.
