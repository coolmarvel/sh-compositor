# /deploy-check — 배포 전 점검

릴리스/배포 직전에 실행하는 체크리스트. 전부 통과해야 산출물을 전달한다.

## 점검 항목

1. **검증 명령 전체 실행**: CLAUDE.md "자주 쓰는 명령"의 검증(typecheck/lint/test/build 상당)을
   전부 실행하고 결과를 그대로 보고한다 (실패를 숨기지 않는다).
2. **버전 정합**: 버전 파일(package.json 등)·changelog·산출물 파일명이 같은 버전을 가리키는가
3. **.env.example 동기화**: 새로 추가된 환경 변수가 `.env.example` 에 반영됐는가
4. **마이그레이션/스키마**: 스키마 변경이 있으면 마이그레이션 파일과 롤백 경로가 있는가
5. **문서 갱신**: session-log 최상단 블록, todo, changelog 가 이번 릴리스를 반영하는가
6. **민감 파일**: 산출물/커밋 대상에 .env·토큰·개인정보가 섞이지 않았는가

## 출력 형식

항목별 ✅/❌ 와 근거(명령 출력 요약, 파일 경로). ❌ 가 하나라도 있으면 배포 중단을 권고한다.
